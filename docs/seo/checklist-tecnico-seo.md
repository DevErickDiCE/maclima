# Checklist técnico SEO

## Prioridad P0

- [ ] `/geotermia` responde 200 o se retiran todos sus enlaces hasta crearla.
- [ ] Sitemap generado automáticamente e incluye páginas y artículos publicados.
- [ ] `robots.txt` apunta al sitemap canónico.
- [ ] Dominio principal y canonicals son coherentes.
- [ ] Search Console está verificada y recibe el sitemap.
- [ ] No hay páginas clave con `noindex` accidental.

## Metadatos y estructura

- [ ] Título y descripción únicos por página.
- [ ] Un H1 claro por URL.
- [ ] Canonical autocontenido y absoluto.
- [ ] Open Graph con imagen válida.
- [ ] Breadcrumbs visibles y `BreadcrumbList` cuando se implementen.
- [ ] `BlogPosting` usa fechas reales de publicación y modificación.
- [ ] Datos de entidad coinciden con NAP real.

## Contenido y rastreo

- [ ] Blog y artículos aparecen en sitemap.
- [ ] No hay enlaces internos rotos.
- [ ] Páginas pilar enlazan a sus artículos principales.
- [ ] Artículos huérfanos: cero.
- [ ] Imágenes tienen dimensiones, peso razonable y alt útil.

## Rendimiento y experiencia

- [ ] Revisar Core Web Vitals de campo cuando haya datos.
- [ ] Verificar móvil, teclado y contraste.
- [ ] Comprobar CLS en imágenes y componentes dinámicos.
- [ ] Formularios muestran éxito y error comprensibles.

## Medición y privacidad

- [ ] Evento de envío de formulario.
- [ ] Evento de clic a WhatsApp.
- [ ] Evento de clic a teléfono.
- [ ] Eventos de CTA desde artículos.
- [ ] Política de cookies y consentimiento actualizados antes de activar analítica no necesaria.
