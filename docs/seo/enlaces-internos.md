# Mapa y reglas de enlazado interno

## Regla mínima por artículo

1. Página pilar del clúster.
2. Un artículo relacionado del mismo clúster.
3. Una pieza de decisión complementaria o catálogo.
4. Consultoría gratuita o CTA equivalente.

No añadir enlaces solo para cumplir una cifra. Deben ayudar a continuar la decisión.

## Anchors

Variar de forma natural:

- “instalación de aerotermia en Madrid”;
- “soluciones de aerotermia”;
- “estudiar una instalación de aerotermia”;
- “asesoramiento fotovoltaico”;
- “consultoría energética gratuita”.

Evitar repetir el mismo anchor exacto en todos los contenidos.

## Enlaces desde pilares

Cada página pilar debe enlazar a:

- guía de precio;
- guía de viabilidad o dimensionamiento;
- comparativa principal;
- mantenimiento;
- caso o evidencia real cuando exista.

Revisar estos bloques al completar las primeras ocho publicaciones.

## Enlaces externos

- Abrir únicamente cuando aporten prueba o trámite útil.
- Priorizar fuentes oficiales y fabricantes.
- No enlazar a un competidor desde una CTA o afirmación comercial si una fuente primaria puede respaldarla.
