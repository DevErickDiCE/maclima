# Prompt — REVISAR CONTENIDO SEO

```text
REVISAR CONTENIDO SEO: <slug>

1. Identifica el artículo y su fila del calendario.
2. Lee la página pilar y como máximo cinco contenidos relacionados.
3. Revisa intención, canibalización, claridad, exactitud, fuentes, enlaces, CTA y frontmatter.
4. Comprueba de nuevo cualquier dato sensible al tiempo.
5. Señala qué requiere validación técnica, comercial, legal, fiscal o de seguridad.
6. Corrige solo lo respaldado; no inventes datos faltantes.
7. Si supera la revisión, cambia el artículo a status: revision y la fila a revisado.
8. Ejecuta npm run seo:index, npm run lint y npm run build.

No publiques, no hagas commit y no hagas push sin autorización explícita.
```
