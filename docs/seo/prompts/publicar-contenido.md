# Prompt — PUBLICAR CONTENIDO SEO

```text
PUBLICAR CONTENIDO SEO: <slug>

Esta orden autoriza a preparar la publicación, pero solo autoriza commit, push o despliegue si el usuario lo dice de forma explícita.

1. Confirma que el artículo está revisado y que no quedan bloqueos.
2. Verifica fuentes temporales y aprobación técnica/comercial.
3. Cambia el frontmatter a status: publicado y completa updated_at.
4. Actualiza calendario con status publicado, fecha_publicacion y URL.
5. Ejecuta npm run seo:index, npm run lint y npm run build.
6. Comprueba canonical, sitemap, metadatos, schema, imagen, enlaces y CTA.
7. Prepara una adaptación social coherente sin publicarla automáticamente.
8. Informa del resultado y de la fecha recomendada para revisar indexación.
```
