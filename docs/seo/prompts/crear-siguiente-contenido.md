# Prompt — SEO SIGUIENTE ARTÍCULO

```text
SEO SIGUIENTE ARTÍCULO: Maclima

Trabaja en el repositorio actual y respeta AGENTS.md.

1. Lee docs/seo/calendario-publicaciones.csv y docs/seo/registro-publicaciones.csv.
2. Elige la fila pendiente con fecha más antigua cuya dependencia técnica esté resuelta.
3. Comprueba solapamientos por título, slug, keyword, intención y clúster.
4. Lee como máximo cinco artículos relacionados y la página pilar.
5. Cambia la fila elegida a en_redaccion.
6. Investiga fuentes actuales según docs/seo/fuentes-confiables.md.
7. Crea un borrador siguiendo docs/seo/guia-estilo-articulos.md y docs/seo/enlaces-internos.md.
8. No inventes precios, ahorros, subvenciones, casos ni métricas.
9. Deja status: borrador hasta revisión humana.
10. Ejecuta npm run seo:index, npm run lint y npm run build.
11. Informa de archivos, fuentes, riesgos y revisiones pendientes.

No hagas commit, push, despliegue ni publicación social sin autorización explícita.
```
